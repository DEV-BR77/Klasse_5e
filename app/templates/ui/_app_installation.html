KlassID als App installieren

Installiere KlassID auf deinem Gerät für einen ständigen Zugriff.

Android

  1. Öffne KlassID in Chrome und melde dich an.
  2. Tippe auf das Menü ⋮.
  3. Wähle „App installieren“. Falls dieser Punkt fehlt, wähle „Zum Startbildschirm hinzufügen“.
  4. Bestätige die Installation.

iOS-Geräte

  1. Öffne KlassID in Safari und melde dich an.
  2. Tippe auf „Teilen“.
  3. Wähle „Zum Home-Bildschirm“.
  4. Tippe auf „Hinzufügen“.

In unterstützten Browsern kannst du die Installation auch direkt starten.
