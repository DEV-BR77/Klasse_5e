# Interaktives Tutorial

Das Tutorial ist eine optionale, serverseitig gerenderte Tour nach dem Onboarding. Es erklärt Dashboard, Kalender, Kommunikation, Familie/Einwilligungen, Benachrichtigungen und Datenschutz/Widerruf. Fortschritt wird pro Konto gespeichert; das Tutorial kann übersprungen, pausiert, neu gestartet und über „Mehr → Tutorial“ jederzeit geöffnet werden.

Es benötigt keine Analyse-, Tracking-, Video- oder Fremdskripte. Jede Seite funktioniert ohne JavaScript. Kurze Texte, eine konkrete Übung und „Zurück/Weiter/Beenden“ sind per Tastatur erreichbar. Für Schüler werden Begriffe vereinfacht. Ein optionales späteres Video darf keine produktiven Daten zeigen und braucht Untertitel/Transkript.
