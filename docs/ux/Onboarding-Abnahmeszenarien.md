# Onboarding-Abnahmeszenarien

| Szenario | Erwartung |
|---|---|
| neues Elternkonto | Identität/Beziehung sichtbar, alle optionalen Zwecke aus, Pause möglich |
| Schüler-Login | kindgerechte Texte; keine Vertretungsentscheidung für andere |
| getrennte Eltern | Zustimmung nur wirksam, wenn alle aktuell Berechtigten zustimmen |
| unbestätigte Beziehung | keine Kindentscheidung, klare neutrale Erklärung |
| alles ablehnen | Abschluss und Kernportal funktionieren |
| teilweise zustimmen | ausschließlich gewählte Zwecke aktiv |
| vollständiger Widerruf | sofortige Sperre und zweckspezifische Bereinigung |
| neue Textversion | nur betroffener Zweck erneut offen; alte Entscheidung historisch |
| Biometrie ohne Freigabe | nicht aktivierbar, auch nicht über direkte Anfrage |
| direkte Schritt-/Objekt-URL | Server prüft Zustand und Rechte |
| Tastatur | logische Fokusfolge, alle Aktionen mit Enter/Leertaste erreichbar |
| 320–1440 px / 200 % | kein Inhaltsverlust, kein horizontaler Seiten-Scroll |
| Sprache/Dark Patterns | Ja/Nein gleichwertig, keine Vorauswahl, keine Schuld-/Drängeltexte |
