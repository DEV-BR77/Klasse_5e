# WebUntis-Funktionskatalog

Jede Datenart ist je persönlicher Verbindung und Kind getrennt schaltbar. Ein deaktivierter Schalter verhindert Abruf und Darstellung; Administratorrollen ersetzen weder die Beziehung noch die persönliche Freigabe.

| Datenart | Zweck im Portal | Startstatus |
|---|---|---|
| Stundenplan | persönlicher Tages- und Wochenplan | einzeln freigeben |
| Änderungen/Vertretungen | aktuelle Abweichungen vom Stundenplan | einzeln freigeben |
| Hausaufgaben | persönlicher Überblick, Eltern lesen, Schüler markieren erledigt | einzeln freigeben |
| Prüfungen | angekündigte Termine | einzeln freigeben |
| Abwesenheiten | persönlicher Import und ausdrücklich ausgelöste Meldung | einzeln freigeben |
| Ferien, Schuljahr, Stundenraster | Kontext für Kalenderdarstellungen | einzeln freigeben |
| Fächer, Räume, Lehrkräfte | ergänzende Stundenplaninformationen | einzeln freigeben |

Persönliche Mitteilungen bleiben deaktiviert, bis die Quelle, Datensparsamkeit und Leseberechtigung gesondert geprüft sind. Jede Verbindung kann vollständig entfernt werden; dabei verschwinden Zugangsdaten und die davon abhängigen lokalen Importdaten.
