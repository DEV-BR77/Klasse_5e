# DSFA-Vorprüfung: biometrische Gesichtssuche

Ergebnis: Eine Datenschutz-Folgenabschätzung ist erforderlich. Die Verarbeitung betrifft biometrische Daten Minderjähriger, erfolgt potenziell systematisch über eine Bildsammlung und kann bei Fehlern, Missbrauch oder Datenabfluss hohe Auswirkungen haben.

Bis zur dokumentierten Freigabe bleiben globaler Feature-Schalter und alle individuellen Einstellungen aus. Ein Pilot ohne echte biometrische Daten ist als technische Trockenübung zulässig; ein Realbetrieb nicht.

Auslöser für erneute Prüfung sind insbesondere Modellwechsel, externe Verarbeitung, neue Empfänger, Ausweitung auf Anwesenheit/Identifikation, längere Speicherfristen, zusätzliche Klassen oder geänderte Schutzmaßnahmen.
