# Widerrufsprozess

1. Die Person öffnet „Mehr → Einwilligungen“ und wählt beim einzelnen Zweck „Widerrufen“. Derselbe Weg ist ohne Nachricht an Dritte möglich.
2. Der Server prüft Identität, bestätigte Vertretungsbeziehung, Zuständigkeit und aktuelle Entscheidung.
3. Eine neue unveränderliche Widerrufsentscheidung wird gespeichert; frühere Nachweise bleiben historisch.
4. Die Funktion wird synchron gesperrt. Danach laufen zweckspezifische Bereinigungen: Profilfelder verbergen, Push deaktivieren, WebUntis-Kategorie sperren/Zugang auf Wunsch löschen, Biometriedaten löschen, Fotos prüfen.
5. Die Oberfläche bestätigt Wirkung, noch laufende Löschschritte und Kontaktweg. Fehlschläge landen ohne Inhaltsdaten in einer Betriebsliste und werden erneut versucht.
6. Ein späteres Opt-in erfordert die dann aktuelle Textversion; es stellt gelöschte Daten nicht automatisch wieder her.

Bei mehreren Sorgeberechtigten wirkt der Widerruf einer berechtigten Person sofort konservativ für das Kind. Eine andere Zustimmung überstimmt ihn nicht.
