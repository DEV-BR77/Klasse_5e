# WebUntis-Funktionskatalog

| Schlüssel | Kategorie | Standard | Abruf | Speicherung im Pilot |
|---|---|---|---|---|
| `webuntis_timetable` | Stundenplan | aus | manuell | nur technisches Ergebnis/Status, keine Fachdaten |
| `webuntis_timetable_extended` | erweiterte Stundeninfos | aus | manuell | keine Fachdaten |
| `webuntis_substitutions` | Vertretungen | aus | manuell | keine Fachdaten |
| `webuntis_homework` | Hausaufgaben | aus | manuell | keine Fachdaten |
| `webuntis_exams` | Prüfungen | aus | manuell | keine Fachdaten |
| `webuntis_holidays` | Ferien | aus | manuell | keine Fachdaten |
| `webuntis_timegrid` | Stundenraster | aus | manuell | keine Fachdaten |
| `webuntis_subjects` | Fächer | aus | manuell | keine Fachdaten |
| `webuntis_rooms` | Räume | aus | manuell | keine Fachdaten |
| `webuntis_teachers` | Lehrkräfte | aus | manuell | keine Fachdaten |
| `webuntis_schoolyears` | Schuljahre | aus | manuell | keine Fachdaten |
| `webuntis_statusdata` | Statushinweise | aus | manuell | keine Fachdaten |
| `webuntis_absences` | Abwesenheiten (Adapter derzeit nicht unterstützt) | aus | kein Abruf | keine Fachdaten |

Neue Kategorien benötigen eigenen Zweck, Textversion, UI-Schalter, Berechtigungs- und Datenschutzprüfung. Sammelaktivierung und implizite Aktivierung sind ausgeschlossen.
